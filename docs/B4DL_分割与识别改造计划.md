# B4DL 分割与识别改造计划

## 目标

在保留 B3 文本问答能力的前提下，增加“当前帧完整 LiDAR + 自然语言问题 → 多个对象的点级掩码、固定类别和简短说明”。首版支持 nuScenes 十类物体、左右/前后/远近关系和一问多目标；多帧融合、跟踪与开放词汇留作后续扩展。

## 论文方法映射

- MORE3D：每个 `<SEG>` 隐状态对应一个对象查询，用于可变数量的多目标掩码；掩码头与类别头分离。
- Reason3D：每个 `<LOC>` 先预测连续粗区域概率，再作为 `<SEG>` 精分割的软先验。
- B4DL：保留 Vicuna、B3 LoRA 和 Stage 1 投影器；新增完整三维稀疏编码器、128 个空间查询和点到体素反向映射。

## 远端核查后的加载决定

AutoDL `/root/autodl-tmp/mmb4dl` 实测为 Python 3.10.20、PyTorch 2.8.0+cu128、Transformers 4.47.0、PEFT 0.13.2。历史 B3 checkpoint 为约 3 epochs，词表大小 32002，并在 `non_lora_trainables.bin` 中保存完整输入词嵌入。

因此必须先完整恢复并合并 B3，再追加 `<LOC>`、`<SEG>`、`<NOOBJ>`。新 token 编号固定为 32002—32004。它们的输入增量与输出预测行独立训练和保存，不能只训练输入嵌入，也不能在加载 B3 前扩词表。

## 数据和训练

使用 nuScenes trainval 原始点云、lidarseg 语义预训练和 panoptic 实例监督。按场景划分数据并隔离 B4DL 测试场景。标注只用于生成训练目标和评测，绝不进入模型输入。

训练顺序：数据/几何闭包 → 稀疏空间编码预训练 → 单目标分割 → 多目标路由和粗定位 → 自由生成评测 → Gradio 展示。最终对比类别名称基线、仅 `<SEG>`、完整 `<LOC>/<SEG>`，至少运行三个随机种子。

## 验收

- B3 32002 到分割 32005 的加载、保存、恢复和旧路径兼容通过测试。
- 32 条固定样本在 teacher forcing 下平均实例 IoU 达到 0.90，随后单独检查自由生成 token 成功率。
- 报告 cIoU、gIoU、实例精确率/召回率、类别宏 F1、目标数量准确率、无目标误报率、token 失败率、延迟和峰值显存。
- 小目标、远距离、同类干扰及空间关系查询分别报告；漏检和额外预测不能从指标中剔除。

## 当前实施状态

远端 `main` 已确认与 `origin/main` 一致，更新前备份分支为 `backup/pre-seg-sync-20260917`，开发分支为 `seg`。代码已包含模型加载、分割头、lidarseg 空间编码预训练、无歧义多实例数据生成、32 条固定样本 teacher-forcing 验证与早停、自由生成评测、自描述 checkpoint 和 Gradio 接口。目标实例训练仍受 panoptic expansion、spconv 和可用 CUDA GPU 约束；预检在资源不完整时会明确停止。
