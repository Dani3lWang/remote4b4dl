## 0. 十秒总览

```
[B5-P0] lidarseg 数据门（零 GPU，~0.5 天）        → agent_labels.json（sample_token 键控）
[B5-P1] token 级特征质量门（5090，~0.5-1 天）      → token 特征 + Linear 探针报告  ★决策点
[B5a]  路线 A：分类头 + <AGENT> 元数据注入（1-3 天，不动 LLM 主干）
        B5a-1 分类头训练 → B5a-2 全量推理 → B5a-3 注入 → B5a-4 stage3 短微调 → B5a-5 评测
[B5b]  路线 B：<SEG> token + 分离式解码头（~1 周，MORE3D 式）
        B5b-1 token 特征提取 → B5b-2 解码器模块 → B5b-3 联合训练 → B5b-4 评测+接口冻结 →（可选 B5b-5 数据引擎）
衔接：  B5b-4 = 输出接口冻结点，必须先于 RL M2；RL M1（零 GPU）可并行
```

依赖 DAG：B5-P0 是 B5a/B5b 共同前提；B5-P1 是 B5b 前提（也是 B5a 用 token 特征的前提）；
B5a 不依赖 B5b，可独立交付；B5b 训练以 B3 产物为初始化（与 RL 同一初始化约定）。

## 1. 论文技术 → 移植决策表

| 论文技术 | 来源 | 决策 | 理由 / 替代方案 |
|---|---|---|---|
| [SEG] token 隐藏态驱动解码头 | Reason3D / MORE3D | ✅ 移植（B5b） | 与 metatoken 家族同构，注册与梯度掩码约定现成 |
| 分离式 mask/class 双分支 | MORE3D Table 3 | ✅ 移植 | 分离式 +1.13 cIoU（30.19 vs 29.06） |
| BCE+DICE 掩码损失 | 两篇共用 | ✅ 移植 | Reason3D 消融：单用 BCE 30.86 / DICE 41.73 / 合用 43.21 |
| 文本+掩码联合监督 | MORE3D Table 4 | ✅ 移植 | 缺任一损失 cIoU 暴跌 16+ 点 |
| coarse-to-fine 区域先验（[LOC]） | Reason3D | ⏸ 缓行 | 对应"先段落、后帧"两级 TG，列入后续版本，不在 B5 范围 |
| GPT-4o+掩码叠加数据引擎 | MORE3D | 🔄 替代 | nuScenes **lidarseg 官方逐点标签免费**，基础分类无需合成；推理型指令（B5b-5 可选）才用它 |
| 超点池化 | Reason3D | 🔄 替代 | LiDAR-CLIP `AttentionPool2d.no_pooling` 已可输出 token 级特征（见 §2） |
| FlanT5 / 室内编码器 / ReasonSeg3D 基准 | — | ❌ 不移植 | 底座与域不匹配；数字不可跨域比较 |
| **创新点声明** | — | — | 两篇论文均限**室内静态**场景；驾驶动态目标分类/推理分割为空缺，B5 系列即论文贡献点 |

## 5. B5-P1 特征门：token 级特征质量探针 ★决策点

### 5.1 提取脚本 `encoders/lidarclip/extract_token_features_sample.py`

- 以 `extract_pc_features_sample_token.py` 为底，前向改走
  `AttentionPool2d.forward(..., no_pooling=True)` 分支（`attention_pool.py:42-44`），
  输出 `{sample_token}_tokens.npy`，shape `(T, 768)` fp16（T = SST token 网格数，实测写入本节）。
- 加载约定不变：`weights_only=False` + `strict=False`、lidar encoder train 模式（与 `val_mse_probe.py` 一致）。

### 5.2 Linear 探针 `encoders/lidarclip/probe_agent_head.py`

- 冻结 token 特征，线性分类 8 动态类（B5-P0 标签，逐 token 点级监督下采样到 token 网格），
  train/val 场景切分沿用官方 700/150。

  - pass（双开 B5a token 版 + B5b）：probe mIoU ≥ 多数类基线 +30 pt，且 pedestrian/bicycle 两稀有类 F1 ≥ 0.5；

  - 无论 pass/fail，探针 CSV 追加到 `logs/probe_agent_head.csv` 存档。

## 6. 路线 A（B5a）：分类头 + `<AGENT>` 元数据注入

### B5a-1 分类头训练（`encoders/lidarclip/train_agent_head.py`）

- 结构：`Linear(768, 512)-ReLU-Linear(512, 8)`（≈0.6M 参数，MORE3D 分离式 class 分支同构）；
- 损失：逐 token CE（8 类 + background），类别加权（逆频率）对抗稀有类；
- 产物：`b4dl/agent_head/agent_head.bin`；耗时 ~1h（28k 帧 token 特征，bs 大、单卡轻松）。

### B5a-2 全量推理（`encoders/lidarclip/export_agent_stats.py`）

- 对 **850 场景全部关键帧**（含测试 150 scenes）前向 → `agent_stats/{scene_id}.json`：
  每帧 `{counts, ratios}`（8 类）。
- **红线（oracle 边界）**：`agent_stats` 全部来自分类头自身输出，**训练/测试两侧同源**；
  lidarseg GT 只允许出现在 `agent_labels.json`（训练监督），测试侧任何 GT 框/标签不得进入输入渲染。
  可选消融：train 侧改用 GT 统计对照（标注 oracle，仅作分析不进主表）。

### B5a-3 `<AGENT>` 注入（`mllm/scripts/inject_agent_token.py` + `ego_text.py` 扩展）

- 渲染规范（追加在现有 `<meta>` 文本尾部，同一渲染函数产出）：

  ```
  <meta> The metadata of the first frame is '...' ... Active agents near the ego car:
  3 cars, 1 pedestrian, 0 buses. </meta>
  ```

- **双模式**：默认关（B3 口径逐字符不变）；`--agent_stats` 开启后才追加；
  `test_b4dl.py build_query` 同步加同名参数，保持**训练-评测逐字符一致**（CLAUDE.md §已知问题 251 行警告的同款约束）；
- 幂等：输入文件哈希 + 输出行数断言（照抄 `oversample_tg_highframe.py` 的写前断言 + 写后校验）。

### B5a-4 stage3 短微调

- 驱动：新 `scripts/run_b5a_pipeline.sh`（仿 `run_b3_pipeline.sh`；Phase A 跳过——直接用 B3 merged 基座）；
- 数据：`stage2_full_train_seqv3_meta2_agent_148k.json`；
- 快验：1 epoch（~1074 步量级）→ 只跑 TG + existence 快评，确认不回退再放全量 3 epochs。

### B5a-5 评测与验收

| 指标 | 口径 | 验收线 |
|---|---|---|
| TG mIoU | 现有 `compute_miou`（不回退） | ≥ 0.3467 − 0.013（B3 显著线以下即回退） |
| existence/binary acc | 现有 `compute_accuracy` | ≥ B3 水平 |
| agent QA（新增，离线评） | 从 `agent_labels.json` 构造 ~500 条 "How many cars/pedestrians appear?" 离线集，acc | 显著高于 B3 同题抽样（分类能力注入成功的直接证据） |
| agent 统计保真（可选） | 分类头统计 vs GT 统计的 per-class MAE | 存档作误差上限分析 |

## 7. 路线 B（B5b）：`<SEG>` token + 分离式解码头（MORE3D 式）

### B5b-2 解码器模块（新 `mllm/vtimellm/model/seg_decoder.py`）

```
h_seg ∈ R^4096  ──W_proj(4096→768)──▶ q ──dot── F_p (T,768) ──▶ mask 分支 Linear-ReLU-Linear → (T,) logits
                                     └──▶ class 分支 Linear-ReLU-Linear → (8,) 类别 logits
```

- 机制 = MORE3D 点积融合 + 分离式双分支；参数 <10M，显存可忽略；
- 损失：`L = L_ans + L_mask + L_cls`（等权；`L_mask = BCE + DICE`，帧级 mask = GT TG 帧集合）；
- 首版范围克制：**只对 TG 任务开启**解码头（文本输出保留，双口径并存），避免一次性改六任务。

### B5b-3 训练侧接线

| 文件 | 改动 |
|---|---|
| `train/dataset.py` | TG 样本额外产出 `frame_mask`（GT start/end → 0/1 向量，长度 = feat_indices 数） |
| `train/train.py` | 注册 `<SEG>` token（复用 train.py:230/325 扩容路径）；解码头参数加入可训练组；梯度掩码约定同步（metatoken embedding 单卡 wd=0 同款） |
| `model/vtimellm_llama.py`（或 arch） | forward 末尾：TG 样本取 `<SEG>` 位置隐藏态 → 解码头 → `seg_logits` 随 outputs 返回 |
| `train/vtimellm_trainer.py` | compute_loss 追加 `L_mask + L_cls` |

### B5b-4 评测与接口冻结

- `evaluate_model.py` 新增 `compute_per_class_iou`（8 类）与 TG **双口径**：
  旧文本 parse 口径（兼容对照）+ 解码头 mask 口径（argmax→帧集合→`compute_miou`）；
- **输出接口冻结**：mask→帧集合的解析函数（输入 JSON 结构、字段名）在此步定稿并写回本节，
  该函数即未来 RL 奖励的直接引用点——**冻结前不启动 RL M2**；
- 验收线：解码头口径 TG mIoU ≥ B3 文本口径（0.3467）为成功；±0.013 内视为持平（工程改动不伤基线）。

### B5b-5（可选）推理型分割指令数据

- MORE3D 数据引擎的驾驶版：nuScenes 渲染图 + GT 框/时序叠加 → GPT-4o 生成
  "segment the vehicle that yields at the crosswalk" 类 QA；**仅训练侧**，测试集不引入；
- 触发条件：B5b-4 通过且论文需要"推理型分割"章节时再启动（避免数据分散火力）。

## 8. 与 RL 里程碑的衔接（时序硬约束）

| RL 里程碑 | 与 B5 的关系 |
|---|---|
| M1 奖励离线审计（零 GPU） | **可并行**；审计表追加 agent 分类 acc、（若 B5b-4 已冻结）mask-IoU 两列 |
| M2 rollout 冒烟 | **必须在 B5b-4 之后**：奖励函数引用冻结后的帧集合解析接口 |
| M3 单任务 RL | 起点建议仍用 B3 口径（变量隔离）；B5 口径作为第二批对照 |
| M4 多任务扩展 | 奖励映射表（RL 底稿 §7.2）增行：agent 分类 → accuracy 奖励；TG mask → mIoU 奖励（与评测同构，天然 RLVR） |

一句话时序：**B5a 可随时插入；B5b 必须在 RL M2 前定型接口**（否则 RL 训完再改输出格式 = 全部重跑）。

| token 级特征线性不可分（SST backbone 为检测预训练，未见分割监督） | 中 | B5-P1 预注册门槛；fail 则 B5a 降级帧级统计版，B5b 挂起（不影响主线） |
| 测试侧分类头统计噪声 → 渲染文本误导 TG | 低-中 | 只渲染计数 ≥ 阈值的高置信类；阈值进消融 |
| 训练-评测代际混用（agent 开/关不一致） | 低 | 双模式 + 启动断言（数据文件名含 `agent` 则强制 `--agent_stats`） |
| 显存：5090 共存（CoRViD 门控） | 低 | 分类头/解码头 <10M；训练沿用显存门控 cron 约定 |
| lidarseg 下载受阻（需官网账号） | 低 | 服务器手动下载；键控校验兜底 |
| B5b 改 forward 引入回归 | 中 | B5b-2 独立模块 + TG 单任务开启 + B3 初始化同口径对照 |

**全局红线**（重申）：lidarseg/框 GT 只进训练监督与离线评测，测试侧输入渲染只用模型自身感知输出；
`feat_indices` 的 oracle 语义已在 RL 底稿 §7.5 声明，B5 不新增越界。

## 11. 时间账（单卡 5090）
