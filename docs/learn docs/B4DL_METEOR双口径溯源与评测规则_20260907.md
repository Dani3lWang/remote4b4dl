# B4DL METEOR 双口径规则

## 当前规则

`B4DLEvaluator(meteor_backend='dual')` 同时记录：

- `meteor`：NLTK-2005，作为与论文比较的主口径；
- `meteor_pycocoevalcap`：Meteor-1.5 jar，只作兼容参考，需要系统 Java。

论文引用 Banerjee & Lavie 2005，因此主报告统一采用 NLTK-2005。不同后端的数值不可直接横向比较。

## B3 历史锚点

历史 3-epoch B3 checkpoint 的 NLTK-2005 METEOR 为 0.3366，论文报告为 0.275。该数字只用于评测实现和搬运后的口径核验，不代表当前 2-epoch 配方的实测成绩。

## 报告要求

1. 明确写出 METEOR backend。
2. 与论文比较使用 `meteor`。
3. 同时保留 `metric_backend` 元数据。
4. 若 jar 或 WordNet 等依赖不可用，必须在结果中报告降级，不能静默把 0 当成有效成绩。
