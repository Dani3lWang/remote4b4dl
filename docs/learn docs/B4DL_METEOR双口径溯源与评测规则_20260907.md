# B4DL METEOR 口径溯源与双后端评测规则（2026-09-07）

> 解决"唯一未对齐指标"悬案：论文 METEOR=0.275 的口径考证 + 评测代码双后端化 + B0-B3 双口径补算。
> 代码：`mllm/evaluation/evaluate_model.py`（dual 模式）、`mllm/evaluation/recompute_dual_meteor.py`。

## 一、结论速览

1. **论文引用溯源**：B4DL 论文 §3.1 指标句引用 [2] = Banerjee & Lavie 2005（ACL Workshop W05-0909）。该论文定义的 METEOR 参数为 **α=0.9（Fmean=10PR/(R+9P)）、β=3.0、γ=0.5，模块 exact→Porter 词干→WordNet 同义、无 paraphrase** —— 这**正是 NLTK `meteor_score` 的实现与参数**（逐项核对一致）。
2. **现冻结口径的定位偏差**：此前冻结的 pycocoevalcap Meteor-1.5 jar（rank 默认 0.85/0.2/0.6/0.75 + paraphrase + 模块权重）是 **2014 年为 WMT 重新调参**的变体，**不是论文引用 [2] 的内容**。用它与 0.275 对比得到的"0.175 低于论文"是口径错配造成的假象。
3. **NLTK-2005 口径下复现结果全部超论文**：B0-B3 = 0.3344 / 0.3371 / 0.3362 / **0.3366**，均 > 论文 0.275（B3 +0.062）。与 BLEU-4/ROUGE-L/BERTScore 三项命中/超出论文的结论**全链路自洽**（METEOR 不再孤立偏低）。
4. 论文 0.275 仍无法逐位复现（落在 0.14~0.38 变体区间内），但其引用 [2] 的实现方向明确指向 NLTK-2005；即使按该口径我们已高于论文，无碍"生成质量对齐/超论文"结论。

## 二、溯源证据链

### 2.1 B4DL 论文文本（docs/mmb4dl.pdf）
- 指标句（PDF 第 3 页 §3.1 Task Definition）："we employ BLEU-4 (B@4) [23], METEOR [2], ROUGE-L [16], and BERTScore [5]"。
- §5.1："each metric is computed per task and then averaged"（与实现一致：per-task 计算、complex 三任务等权平均）。
- 参考文献 [2]（PDF 第 9 页）：Banerjee & Lavie 2005，METEOR，ACL Workshop on Intrinsic and Extrinsic Evaluation Measures for MT and/or Summarization, pp. 65-72。
- 注意：[5] 引的是 Devlin et al. 2019 BERT 而非 BERTScore 论文（Zhang et al. ICLR 2020）——论文指标引用记录粗糙，佐证 0.275 无法从论文文本考证。

### 2.2 引文 [2]（/tmp/meteor2005.pdf，ACL W05-0909，印刷页 65-72）
- §2.2 The METEOR Metric：`Fmean = 10PR/(R+9P)`（印刷页 67）→ 数学等价于 NLTK 的 `PR/(αP+(1−α)R)` 在 α=0.9 时。
- `Penalty = 0.5 × (#chunks/#unigrams_matched)³`（印刷页 68）→ 即 γ=0.5、β=3.0。
- `Score = Fmean × (1 − Penalty)`；多参考逐参考取 best；系统总分 = 全测试集聚合统计。
- 默认模块顺序 exact → Porter stem → WN synonymy（无 paraphrase，模块等权）。
- §3.6 模块消融（句子级 human-correlation）：Exact 0.312/0.293 → +Porter 0.329/0.318 → +WN-Synonym 0.347/0.331（阿语/汉语）。

### 2.3 三实现对照（同一份 B0 预测实测）
| | NLTK meteor_score | Meteor-1.5 jar rank | 论文引用 [2]（2005） |
|---|---|---|---|
| α/β/γ | 0.9/3.0/0.5 | 0.85/0.2/0.6/0.75 | 0.9/3.0/0.5 |
| 模块 | exact+stem+WN 同义 | +paraphrase、加权 | exact+stem+WN 同义（等权） |
| B0 分数 | 0.3344 | 0.1729 | ≈NLTK（忠实实现） |

### 2.4 变体敏感性扫描（2026-09-07，B0 预测 16,067 文本段）
同一份预测不同变体 → 0.141~0.381，论文 0.275 落在区间内：jar rank 默认 0.1729 / 0.1761（batch）；jar adq 0.3172；jar hter 0.3810；去 paraphrase 0.1686；仅 exact 0.1564；无 -norm 0.1409；NLTK 参数喂 jar 0.3463（验证参数映射）；NLTK+分词小写 0.3331。扫描脚本 `mllm/eval_results/_meteor_sweep/{sweep,sweep2}.py`。
