2. **编码器定稿（08-28 ~ 08-30）**：发现本地 ckpt 是 ONCE 权重而非 nuScenes 版 → nuScenes 自训（高 LR 判停 step 26,550，val MSE 0.1061）→ 短程退火 3ep（1e-4→0，val MSE 0.0992，−6.5%）→ `ckpt_anneal/lidarclip_mm/last.ckpt` 定稿。

4. **B2（09-01 ~ 09-02）**：整场景输入（对齐官方 `--whole_scene`）反证假设——mIoU 0.1992 更差，61% 预测塌缩 "from frame 000 to frame 008"（训练集仅占 9.4%）= 纯先验拟合；40 帧无帧号锚点学不会绝对定位。
5. **官方模型评测（09-02，决定性）**：官方 checkpoint + 官方特征 → acc 0.7542 / mIoU 0.1737；官方训练数据无 meta、无 `<4DLiDAR>` → **论文完整模型从未发布**；对照论文 Table 4"无 Metatoken"行（0.763/0.161）吻合。

## 三、复现阶段的核心认知

1. **meta 渲染语义是 mIoU 的第一瓶颈**（B2→B3 +0.147），大于输入构造（切片 vs 整场景 ±0.06）的影响；
2. **官方仓库不可复现论文 Table 3**——自研 meta 注入是必要路径，且已超论文水平；
3. **编码器特征差异真实但非首要瓶颈**（两套特征余弦相似度仅 0.07-0.11，但 B3 同特征修 meta 即超论文）；
4. **评测口径决定结论可信度**：BERTScore 层号（24→17）、BLEU 语料级两个 bug 修复后才命中论文值——指标对齐先行于模型结论。
