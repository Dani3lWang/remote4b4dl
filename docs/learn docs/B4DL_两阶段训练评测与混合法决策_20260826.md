### 根因分析（已排除 bug 可能）

1. **简单任务格式漂移**：两阶段模型在 existence 上输出
   "Yes, a pedestrian was present on the sidewalk." 而 GT 是 "Yes."；
   评测为 exact match（论文原文即 exact answer matching），导致 accuracy ≈ 0。
   根因：Phase B 用 3 epochs 复杂任务在 merged 模型上叠加新 LoRA，
   长句生成格式覆盖了 Phase A 学到的短答案格式。
2. **TG 坍缩依旧**：预测仅 6 种帧范围，(0,8) 占 88.4%（2460/2783）、
   145 条无帧号、精确命中 175/2783。两阶段法没有改善坍缩，
   且简单任务漂移后 mIoU（0.1614）反而低于混合版（0.1835）。
3. **不是训练没跑对**：两阶段超参（2ep/1e-4、3ep/2e-5）、
   双 LoRA 加载（builder 依次 merge_and_unload）均验证正确。

## 三、决策：修复为混合训练（论文 §4.2 原文）

论文第 4.2 节 4D LiDAR Understanding Stage 原文：

> "The model is trained on **both Simple Tasks and Complex Tasks** ..."

**论文文字描述的正是混合训练**（148K 全量一起训），官方仓库把 stage2/3
拆成两段只是实现选择（沿用 VTimeLLM 惯例）。实测混合版（seqv2-148k）
accuracy 0.7647 超过论文 0.762，而两阶段版简单任务崩坏——因此修复方向为
**回到混合训练**，并叠加本次的新增量：

- 数据：`stage2_full_train_seqv3_148k.json`（148,271 条；TG 13,124 条
  全部恢复 GT 序列归属 + 真实帧 metatoken + feat_indices 精确采样帧）
- projector：95K nu-caption 重训版（替代 699 条欠训练版）
- 超参：3 epochs lr 1e-4（seqv2-148k 同款，该配置 acc 已超论文）
- 状态：**2026-08-26 12:35 已启动**（tmux b4dlmixed，3474 步，
  预计 20-26h，守护 cron 自动收尾评测）

## 四、忠于论文恢复 mIoU 的进一步分析

### 4.1 已排除/已修复的因素

| 因素 | 状态 |
|---|---|
| 数据划分（80/10/10 自创砍 20% 数据） | ✅ 已对齐官方 148K |
| TG 序列归属缺失（喂 40 帧全 scene） | ✅ seqv3 GT 归属恢复（双侧一致） |
| mIoU 闭区间 bug（单帧完美匹配得 0） | ✅ 已修 |
| metatoken per-scene 回退错误 | ✅ v2 任意帧真实渲染 |
| 特征切片区间混入非序列帧 | ✅ feat_indices 精确采样帧 |

### 4.2 剩余差距的候选因素（按嫌疑排序）

1. **stage1 projector 数据量**：95,048 条 ≈ 论文 162K 的 59%。
   项目级映射欠训练会限制帧级定位能力，直接影响 TG。
   → 可补：为剩余关键帧跑 LiDAR-CLIP 特征提取，stage1 数据补到 ~16 万。
2. **TG 评测口径**：实测整数区间 IoU vs 采样帧集合 IoU 差异仅 ±0.02
   （两阶段 0.1614 vs 0.1535；seqv2 0.1835 vs 0.1679），非主要因素。
3. **LiDAR-CLIP 编码器权重**：需核对是否为论文官方发布版（影响全部任务）。
4. **推理解码策略**：当前 greedy；论文未明说（VTimeLLM 默认 greedy，
   大概率一致，可用小样本验证 beam 的影响）。
5. **训练超参细节**：论文单卡 RTX 4090 24h 内训完 148K——与我们
   （5090，~20h）量级一致，lr/epoch 数无官方披露，1e-4×3ep 是仓库默认。

### 4.3 下一步行动计划（全部忠于论文方法）

1. **混合 seqv3 训练**（进行中）——验证 TG 归属在混合法下的净收益，
   预期 accuracy ≥0.76、mIoU 较 0.184 有提升。
2. **核对官方仓库 eval 与编码器**：查官方 mmb4dl-main 的 mIoU 实现细节
   与 LiDAR-CLIP 权重版本，排除实现级差异。
3. **stage1 补数据到 ~162K**：为剩余 ~10K 关键帧提取特征 →
   stage1 重训 → 混合重训。这是 mIoU 差距最大的单一嫌疑因素。
4. 若 1-3 后 mIoU 仍 <0.25：小样本验证解码策略（beam/temperature）
   与 metatoken 措辞的敏感性，再做决策。
