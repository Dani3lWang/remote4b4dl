## 五、数据分析

### 5.1 QA 精度坍缩已修复，混合训练验证成功

- accuracy 0.7629 与论文 0.762 持平，两阶段的 0.0001 彻底消失（existence 0.707、binary_qa 0.819 均健康）；
- 验证了决策判断：混合训练（论文 §4.2 原文做法）是正确路径，两阶段法的格式漂移是固有缺陷（Phase B 长句格式覆盖 Phase A 短答案）；
- 与 seqv2-148k（0.7647）同一水平 → seqv3 数据增量（序列归属 + 真实帧 metatoken + 精确采样帧）对 QA 精度无损。

### 5.2 mIoU +47%，为历史最高，但仍是唯一未达标指标

- mIoU 0.2696 对比：seqv2 0.1835 / 两阶段 0.1614 / baseline 0.1661，改善来自 ① seqv3 的 GT 序列归属 + 真实帧 metatoken + 精确采样帧（训练/评测双侧一致）；② 95K nu-caption 重训 projector；
- 预测多样性改善：33 种 vs 15/6 种，精确命中率翻倍（13.9% vs 6.3%），无帧号预测几乎消失。

### 5.3 与论文消融/缩放的交叉印证（重要旁证）

- **论文 Table 4（metatoken 消融）**：去掉 Metatoken 后 mIoU 从 0.311 掉到 **0.161**（acc 几乎不变 0.763 vs 0.762）——metatoken 对帧级定位的边际作用与我们的修复方向（真实帧逐帧渲染）完全一致；
- **论文 Table 6（数据缩放）**：stage2 数据从 10% 加到 100%，mIoU 0.168 → 0.298 → 0.311，而 accuracy 只从 0.741 → 0.762——**TG 是全模型对数据量最敏感的指标**。这从侧面支持：stage1 投影层只有论文 59% 数据时，最先受损的正是 TG 的帧级定位能力；
- 我们两个"数据侧修复"（序列归属 + 真实帧 metatoken）把 mIoU 从 0.18 拉到 0.27，而论文 metatoken 一项贡献了 0.15（0.161→0.311），说明剩余 0.041 差距中还有投影层表示质量的成分——与 5.2 结论一致。

### 5.4 剩余差距的分解与根因

mIoU 0.270 vs 0.311（差 0.041）的根因证据链：

1. 模型学会了"宽度"（11.1 vs 10.4 帧），没学会"位置"（中心偏移 mean 11.5 帧、99.6% 预测起始帧 <10 帧）→ **先验拟合而非时序定位**；
2. 按嫌疑排序：
   - **① stage1 projector 数据量（最大嫌疑）**：95,048 条 ≈ 论文 162K 的 59%。投影层是单层 Linear(768→4096)，把帧特征映射进 LLM 空间；数据不足 → 学到"场景级"映射而非"帧级"映射 → 模型无法区分帧号 → 无法定位。与"宽度对、位置错"的表现完全吻合（区分帧相对顺序比区分宽度更需要帧级表示）；
   - ② TG 评测口径：整数区间 vs 采样帧集合 IoU 差异仅 ±0.02（已实测排除）；
   - ③ LiDAR-CLIP 编码器权重版本待核对（影响全部任务，对 TG 帧级判别影响最大）；
   - ④ 推理解码策略：当前 greedy，论文大概率一致（低嫌疑）。
