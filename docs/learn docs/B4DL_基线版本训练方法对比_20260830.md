# B4DL 基线版本训练方法对比（B0 vs 直接前一版两阶段 seqv3）（2026-08-30）

> 需求："对比当前基线的训练方法与前一版本基线的训练方法差异"。经两轮澄清最终锁定对比对象：
> **B0（seqv3-mixed 单阶段混合训练）vs 两阶段 seqv3（官方 stage2.sh+stage3.sh 结构）**——
> 时间上紧邻 B0 之前的最后一版训练（两阶段 08-26 10:05 训完，B0 同日 13:19 启动）。
> 本文同时收录对话中完成的其余两组对比（B0 vs 更早版本、B1 vs B0）作为嵌套参考。

## 二、核心对比：B0（seqv3-mixed）vs 两阶段 seqv3

这组对照的特殊价值：两者用**同一份 seqv3 数据、同一个 95K projector、同一份 850 per-scene 特征、同一底座**——全部差异都来自"训练方法"本身，是演进链里最纯粹的一次方法对照。

### 2.1 控制不变的量

底座 vicuna-v1-5-7b（version v1）；数据同源（68,695 简单 + 79,576 复杂 = 148,271 条 seqv3）；95K nu-caption projector（08-25 17:46 重训，742 步）；850 per-scene ONCE 特征；LoRA r64/α128；bs 8×16=128；wd 0；warmup 0.03；cosine；ZeRO-3；bf16；max_len 2048；`freeze_mm_mlp_adapter`。

### 2.2 训练方法差异

| 维度 | 两阶段 seqv3（官方结构） | B0 = seqv3-mixed |
|---|---|---|
| 训练结构 | **两段课程式**：Phase A 简单任务 → LoRA 合并进权重 → Phase B 复杂任务 | **单阶段**：全量数据一次混 shuffle 训完 |
| 数据加载 | Phase A `stage2_train_seqv3.json` 68,695 条（existence/binary/TG）；Phase B `stage3_train_seqv3.json` 79,576 条 | `stage2_full_train_seqv3_148k.json` 148,271 条（同批数据混合） |
| LoRA 结构 | **双 LoRA**：Phase A 的 LoRA 经 `merge_stage2.py` merge_and_unload 烧进 base，Phase B 在 merged 权重上**从零训新 LoRA**；评测需依次加载两个 adapter（`--stage2` + `--stage3`） | **单 LoRA** 一次训完，评测只加载一个 adapter |
| 学习率 | Phase A 1e-4 → Phase B **2e-5**（降 5 倍，官方 stage3.sh 惯例） | 全程 **1e-4**，单一 cosine 调度 |
| Epoch 分配 | 简单任务仅 **2 epochs**，复杂任务 **3 epochs**（简单任务在 Phase B 期间无梯度信号） | 每条数据统一 **3 epochs**，简单+复杂梯度全程共存 |
| 步数 | 1,072（Phase A）+ 1,863（Phase B）= 2,935 步 | 3,474 步 |
| Loss 形态 | Phase A 收敛 0.27（简单任务易），Phase B 1.32 | 稳定 1.05–1.17（混合分布） |
| tf32 | 开（`--tf32 True`） | 关 |
| 训练时长 | Phase A 08-26 00:21 止、Phase B 08-26 10:05 止 | 08-26 13:19 → 08-27 12:14（约 23h） |

### 2.3 结果与机制（方法差异如何决定结果）

**两阶段法失败（acc 0.0001 / mIoU 0.1614），根因是结构性缺陷而非超参错误：**

1. **简单任务格式漂移**：Phase B 只见复杂长句答案，新 LoRA 生成格式被长句覆盖；Phase A 学到的短答案格式（"Yes."/"No."）已烧进 frozen 权重、无人再保护。评测为 exact match（论文原口径），existence 0.0003、binary_qa 0.0，accuracy 整体 0.0001。
2. **TG 坍缩未改善反退**：TG 属简单任务，仅在 Phase A 训 2ep，Phase B 完全不再接触——长句训练冲掉帧范围短格式（145 条输出无帧号，占 5.2%），mIoU 0.1614；预测仅 6 种范围、(0,8) 占 88.4%。

**B0 混合训练同时消解两个问题：**

- 单 LoRA 下简单短答案与复杂长句在全部 3,474 步中持续共存、互相正则，两种格式始终 in-distribution——existence 0.7072 / binary_qa 0.8187 恢复健康，accuracy 0.7629 与论文 0.762 持平。
- TG 全程以 1e-4 训练 3 epochs，mIoU 0.2696（较两阶段 **+67%**）；预测范围扩到 33 种、(0,8) 占比降至 30.7%、精确命中（IoU=1）13.9%、无帧号预测 0.1%。

### 2.4 方法决策的论文依据

论文 §4.2 原文写明 "The model is trained on **both** Simple Tasks and Complex Tasks"——论文描述的正是混合训练；官方仓库拆 stage2/stage3 两段只是沿用 VTimeLLM 惯例的实现选择。这是 B0 锁定为基线、两阶段法被放弃的直接原因。

## 三、B0 与更早版本的差异（嵌套参考）

超参从最初基线到 B0 几乎全程不变（3ep / lr 1e-4 / r64 α128 / bs 8×16 / wd 0 / cosine / ZeRO-3 / bf16 / max_len 2048），特征也一直是同一份 850 per-scene ONCE 特征。训练方法的实际差异集中在数据与 projector。

### 3.1 vs seqv2-148k（直接前一版混合训练）

| 维度 | seqv2-148k | B0 |
|---|---|---|
| 训练数据 | `stage2_full_train_seqv2_148k.json`，148,271 条 | 同条数；seqv3 新增：**TG 13,124 条全部恢复 GT 序列归属**（无帧号 TG 条目从喂整 scene ~40 帧改为包含序列精确采样帧）、metatoken 全部真实帧渲染零 per-scene 回退、feat_indices 精确采样 |
| stage1 projector | 仅 699 条训练的欠训练版 | 95,048 条 nu-caption 重训版（08-25，742 步，覆盖同一路径 `mm_projector.bin`） |
| 超参 | 与 B0 完全一致（含"无 tf32"） | — |
| 评测口径 | 无 `--answer_frames` | 加 `--answer_frames`（oracle 序列归属，口径增量需注明） |

结果：acc 0.7647→0.7629（持平，seqv3 数据增量对 QA 精度无损）；mIoU 0.1835→0.2696（+47%）；TG 预测范围 15 种→33 种，(0,8) 占比 87%→30.7%。

### 3.2 vs 最初基线 baseline(per-scene)（08-12）

| 维度 | 原基线 | B0 |
|---|---|---|
| 训练数据 | `stage2_full_train.json` 118,722 条（自创 80/10/10 划分，砍 20% 数据） | 148,271 条论文官方划分（699 scenes） |
| metatoken/注入 | v1 per-scene 回退渲染 | seqv3 真实帧 metatoken + GT 序列归属 + feat_indices |
| stage1 projector | 699 条欠训练版 | 95K 重训版 |
| 唯一超参差异 | `--tf32 True` 开；save_steps 500 | 关 tf32；save_steps 200（工程项） |
| 特征 | 相同（850 per-scene ONCE，直到 B1 才换编码器重提） | 同左 |

## 四、附：B1 vs B0（当前流水线，供衔接）

B1（tmux `b1pipeline` 运行中）与 B0 的 mixed 阶段**数据与超参完全一致**，差异全在上游两处：

1. **编码器**：原版 ONCE 权重（对齐 nuScenes MSE 0.169，从未对齐本数据）→ nuScenes 自训 + 退火定稿 `ckpt_anneal/lidarclip_mm/last.ckpt`（短程退火 3ep、1e-4→0，val MSE 0.0992）；全部特征一次性重提（stage1 sample_token 28,130 + stage2 per-scene 850）。
2. **stage1 projector 数据**：95,048 条 frame_id 键控 → 161,629 条 sample_token/scene_token 键控（官方 162K 对齐，+70%）；projector 原路径原地重训，B0 的 95K 版已备份 `.bak_95k`。

mixed-b1 使用独立 output_dir（`-mixed-b1`），B0 产物原封不动；评测同口径对照 B0，**ΔmIoU > +0.013 才判显著**。

## 五、结论

1. **B0 与两阶段 seqv3 的差异是纯训练方法差异**（数据/projector/特征全部相同）：单阶段混合单 LoRA vs 两段课程式双 LoRA，学习率调度与 epoch 分配随之不同。
2. 混合法胜出的机制：短/长答案格式全程共存于同一 LoRA 的训练分布，避免两阶段法 Phase B 对 Phase A 格式的覆盖（格式漂移）与 TG 短格式失训（坍缩延续）。
3. 方法选择的权威依据是论文 §4.2 原文的混合训练表述；官方两段结构只是实现惯例，且实测有害。
4. B0 相对更早版本（seqv2/原基线）的差异集中在数据（官方 148K 划分 + TG 序列归属恢复）与 projector（95K 重训），超参几乎未动；编码器换血是 B1 才引入的变量。
