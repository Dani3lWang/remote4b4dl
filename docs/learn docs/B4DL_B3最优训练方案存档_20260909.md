# B4DL B3 基线训练方案

> 当前维护口径：B3、2 epochs。2026-09-06 的 mIoU 0.3467 来自历史 3-epoch checkpoint，只用于结果追溯，不能代表新 2-epoch 配方的实测成绩。

## 保留原因

B3 使用整场景 LiDAR 特征和修复后的 meta2（relative-to-previous）元数据，是现有 SFT 路线中最完整、最稳定且可继续作为 RL 初始化基底的版本。仓库不再维护 B0/B1/B2/B4a 与 frame-position 训练入口。

## 固定配置

| 项目 | 当前值 |
|---|---|
| 训练数据 | `mllm/b4dl_dataset/stage2_full_train_seqv3_meta2_148k.json` |
| 样本数 | 148,271 |
| Stage1 projector | 官方 162K 对齐方案产物 |
| LiDAR 输入 | `--whole_scene True` |
| Epoch | **2** |
| 学习率 | `1e-4`，cosine，warmup ratio 0.03 |
| LoRA | r=64，alpha=128，dropout 使用训练默认值 |
| Batch | micro batch 8，gradient accumulation 16 |
| 精度与并行 | BF16，DeepSpeed ZeRO-3 |
| 最大长度 | 2048 |

实际入口：

```bash
cd mllm
bash scripts/run_b3_pipeline.sh
```

仅训练：

```bash
bash scripts/run_stage2_full_seqv3_mixed_b3.sh
```

仅评测：

```bash
bash run_baseline_eval.sh
```

## 完成判据

训练只有同时满足以下两项才算完成：

1. 输出目录存在 `adapter_model.safetensors`。
2. `trainer_state.json` 中 `epoch >= 1.99`。

脚本按版本号查找最新 `checkpoint-*` 并恢复训练。日志写入 `mllm/training_logs/`，该目录只保存本地运行产物，不应提交。

## 评测口径

固定使用：

```text
--whole_scene --per_sequence --answer_frames
```

预测和指标写入 `mllm/eval_results/b3/`。`--answer_frames` 使用答案恢复输入序列归属，属于 oracle 输入选择，对外报告必须声明。

## 历史结果

历史 3-epoch B3 checkpoint 曾得到：

- mIoU：0.3467
- accuracy：0.7526
- METEOR（NLTK-2005）：0.3366

这些数字用于验证搬运或评测口径是否漂移。2-epoch checkpoint 需要重新完整训练和评测后才能形成新的正式基线数值。
