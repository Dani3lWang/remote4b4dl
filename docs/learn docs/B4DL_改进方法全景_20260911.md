**根因证据链（"输入无显式帧号信号"）**：

## 三、推荐波次与决策树

```
Wave 0（零 GPU，随迁移节奏）: 0d 迁移验收 → 0a M1 → 0b existence 诊断（0c 可选）
Wave 1（1 次训练）:            A.2 帧身份锚点（单变量对照 B3）
Wave 1b（视 A 结果）:          A 显著 → 直接进 Wave 2（或叠加 E/F/G 小步）
                              A 同向未显著 → 叠加 A.1 场景级句 + G 增广再测
                              A 无效 → 转向 E+F 组合 / H 诊断，并重审 TG 评测口径
Wave 2:                        C RFT →（探到天花板）→ I GRPO
储备:                          H、J（并行）
```

优先级理由：A.2 是唯一直接命中已证根因、且成本为"一次训练"的干预；C/I 的奖励信号在输入缺陷未修前会撞同一天花板（TG 奖励=IoU，模型仍无帧号可依）。

## 四、验收与统计口径（防自欺清单）

- **主判据**：ΔmIoU(B−B3) > +0.0132；0<Δ≤0.0132 视为方向正确未达显著（可叠加再测）；Δ<0 判负。
- **TG 专项**：|平均偏差| < 2 帧（B3 −3.90 / B4a −5.96）；GT start≥25（n=413）预测命中数 ≥ 40（B3=13）；桶 mIoU 不低于 B3；top-1 区间占比 ≤30%（B3≈23%；B2 曾 61% 坍缩为反例）；解析率 ≥99.5%。
- **其余五任务**：|Δacc| ≤ 0.0085；BLEU/METEOR(NLTK)/ROUGE/BERTScore 单项 Δ ≥ −0.01。
- **工程口径**：训练到 epoch≥2.99（3,474 步）；评测 0 skip；greedy（do_sample=False）；METEOR 双口径并记；BERTScore OOM 需查日志；对比必须同后端、同测试集、同评测命令（`--whole_scene --per_sequence --answer_frames`）。
- **红线**：训练/评测输入构造同源；`--answer_frames` 的 oracle 归因持续声明；评测集信息（含预测文件）绝不进训练数据。

## 五、对旧策略文档的修正（2026-09-11 核查发现）

1. **动态 padding 收益前提不成立**（D 方向）：`DataCollatorForSupervisedDataset` 已按批内最长 `pad_sequence`，`tokenizer_image_token` 也不做 max_length padding——"1.5-2× 吞吐收益"需重估，先 profile 再动。
2. **B 方向（数据侧 TG 重加权）降级**：`B4DL_训练优化角度分析与策略_20260908.md` §3 的前提（"B4a 已证明数据侧干预有效"）被 B4a 负结果直接推翻。
3. **A.1 文本锚点红线**：TG 的 meta 是 GT 范围渲染（oracle），编号入 meta = 让模型抄答案；只能写场景级范围信息，且机制弱于 A.2。
4. 编号口径小差异：策略文档 E=参数效率（DoRA/r·α/解冻 projector）、F=NEFTune，与口头常说的"E DoRA/NEFTune"不一致。

## 六、可行性核查摘要（本次代码级确认，供后续实施引用）

- **帧锚点落点**：模型侧 `vtimellm/model/vtimellm_arch.py`（`initialize_vision_modules` 建模块、`prepare_inputs_labels_for_multimodal` 投影后相加）、`vtimellm_llama.py`（forward/generate 透传）、`builder.py`（推理侧创建与 `non_lora_trainables.bin` 恢复）；数据侧 `train/dataset.py`（`__getitem__`/collator 产出全局帧索引）、`evaluation/test_b4dl.py`（切片分支同源产出索引）；保存无需改动（`train.py:153-158` 自动收集 requires_grad 的非 LoRA 参数）。
- **索引语义**：场景 npy 行号 i = 场景全局关键帧号 i（与 QA 文本帧号、`feat_indices`/`feat_range` 同源）；整场景模式索引 = `arange(N)`；模型侧无任何现有帧位置编码（已全仓确认）。
- **数据/权重零改动**：148k 训练 JSON 与全部 npy 不动；stage1 projector 复用 B3 的 162K 版（161,629 条）。
- **零初始化可回归**：帧嵌入若零初始化，step 0 前向与 B3 逐位一致，可做"零扰动"对照验证。
