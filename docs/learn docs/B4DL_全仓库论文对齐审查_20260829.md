## 一、总体结论

**复现在方法结构上与论文高度同构（两条主线——数据产物与模型/训练架构——均达到逐项可对齐的保真度），但评测侧存在 3 处此前未发现的指标实现偏差，其中 BERTScore 属可直接修复的 bug，导致 B0 基线的复杂任务文本指标与论文不可比。**

分层对齐度：

| 层 | 对齐度 | 说明 |
|---|---|---|
| 数据集产物（发布版） | **100%** | Table 2 全部 14 个数字实测精确吻合，无一偏差 |
| 模型架构 + 训练管线 | **≈90%** | 三模块、两阶段、冻结策略、token 格式逐项吻合，含一处可辩护的刻意偏差 |
| 编码器 | **高** | 损失/体素化/标定/CLS 拼接全一致；权重溯源问题已用自训权重解决（今晚刚判停） |
| 评测协议骨架 | **高** | 任务路由、exact match、mIoU、聚合公式与论文一致（实测验算逐位通过） |
| 评测指标实现 | **中** | BERTScore ❌ 层号 bug；METEOR ❌ 换库不可比；BLEU-4 ⚠️ 句级 vs 语料级 |
| 数据生成管线代码 | **中** | 官方数据可用，但从 nuScenes 再生数据集缺 TG 生成、HA 注入断链 |
