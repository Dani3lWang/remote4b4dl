# 当前分割瓶颈对应的方法论文与实验映射

核对日期：2026-10-18。结合[阶段性总结](D:/Github/mmb4dl/docs/research/20261018_分割阶段总结/阶段性总结.md)、E1/E2-C 完整交付及当前 decoder/后处理代码选择文献。论文机制、当前实验事实和迁移假设分别记录；推荐顺序依据问题匹配程度，不以发表年份排序。

**优先精读 P3Former 与 Mask3D。** P3Former 更贴近小目标掩码低纯度、相邻实例难分的现象；Mask3D 为现有 E2-Q 提供了可拆分的 query 初始化依据。DQFormer 是中期架构参考；Mask Scoring R-CNN 适合在误检审查确认分数与掩码质量脱节后考虑。当前最先执行的动作仍是人工审查，不是同时复现这些模型。

## 1. 推荐顺序与适用问题

## 2. P3Former：把实例位置约束放进 mask 生成与 query 更新

完整题名：*Position-Guided Point Cloud Panoptic Segmentation Transformer*。出版页确认在线日期为 2024-07-27，正式卷期为 **IJCV 133:275–290 (2025)**。

来源：[出版页](https://link.springer.com/article/10.1007/s11263-024-02162-z)、[方法原文](https://arxiv.org/html/2303.13509v1)、[作者代码](https://github.com/InternRobotics/P3Former)。重点读 §3.2–3.4 及模块消融；方法细节参考这里链接的预印本版本。

**论文机制。** MPE 结合不同坐标参数化的位置表达；PA-Seg 将位置与特征分支用于 mask 预测；MFA 根据融合后的区域更新 query。其出发点包括 LiDAR 实例相对整场景小、同类几何相似，位置差异有助于分离实例。

**项目证据。** E1 中部分 1–2 点漏检目标已被 query 完整覆盖，纯度中位数却只有 0.00221。当前 decoder 已有三维位置编码与多尺度 masked attention，因此问题不能概括成“缺少位置编码”。值得检验的增量是显式位置约束能否改善 mask 的实例边界与纯度。

**最小可检验改动。** 保留骨干、128 queries、体素、损失及推理阈值，在独立实验中只加入/切换一个位置相关的 mask 分支，比较“特征 mask”与“特征＋位置 mask”。若额外容量影响比较，应设置同容量控制；共享参数从同一 F 初始化，新增模块的初始化、优化器重置、实际预算在运行前固定。第一轮不同时引入新的坐标编码、MFA 和骨干。

**判断标准。** 在固定目标集合上同时报告覆盖率、纯度、IoU，以及完整开发集的小目标几何 TP、正确类别 TP、最终 TP/Precision。纯度提高却覆盖率或最终命中下降不算成功；只看成功样本也不够。该建议是受论文启发的局部消融，不等于复现完整 P3Former，收益尚未在本项目验证。

## 3. Mask3D：区分 query 内容初始化与空间位置的作用

完整题名：*Mask3D: Mask Transformer for 3D Semantic Instance Segmentation*，ICRA 2023。

来源：[论文](https://arxiv.org/abs/2210.03105)、[原文 Query Types / Table IV](https://arxiv.org/html/2210.03105v2)。

**论文机制与消融。** Mask3D 使用 query 与多尺度点云特征交互生成实例 mask。Table IV 对比了可学习位置/内容、FPS 位置＋零内容、FPS 位置＋采样特征；相应 mAP 为 39.7±0.7、40.6±0.3、38.4±0.3。该结果支持将位置和内容初始化拆开研究，不能据此保证 nuScenes 极小目标也会提升。

**项目证据。** 当前 [decoder.py](D:/Github/mmb4dl/mllm/maskpls_b4dl/decoder.py:48) 使用可学习的 `query_feat/query_embed`。E1 给出几何不足和低纯度现象，但没有证明初始化就是根因。因此 E2-Q 是值得检验的结构候选，而非已经确定的修复。

沿用[已有 E2-Q 设计](D:/Github/mmb4dl/training_logs/experiment_design_20261017/实验方案.md)，控制共同重置 query 的代价：

| 臂 | 初始内容 | 位置 | 比较意义 |
| --- | --- | --- | --- |
| Q0 | 新可学习 embedding | 新可学习 embedding | 控制 query 重置与重新适应 |
| Q1 | 零向量 | 与 Q0 同初值的可学习 embedding | Q1 对 Q0 分离内容初始化影响 |
| Q2 | 零向量 | ROI 内输入点 FPS 的三维位置编码 | Q2 对 Q1 检验输入自适应位置 |

三臂都保留相同 epoch14 骨干和其余 decoder 参数，重置优化器，全模型训练；不能拿成熟的旧 query 直接与新 query 作唯一对照。每臂 6 轮、1,146 更新，总 3,438 更新；第 0/2/4/6 轮评估，第 6 轮固定为主要终点。零向量指 decoder 的初始内容，后续层仍会更新 query 表征。

运行前明确 FPS 起点、去重和并列距离规则、位置编码尺度及唯一点不足 128 个时的处理。FPS 只消费输入坐标，不用 GT 中心、类别、答案或相机。Q2 必须对 Q0/Q1 均满足原筛选要求；如果只 Q1 受益，只能支持内容初始化变化，不能宣称 FPS 有效。

这属于固定父模型下的 query 重置/适应实验，失败也只说明该路径在限定预算内未通过。新实现的显存和时长尚未测量，不能用旧 E1 推理显存充当训练资源保证。

## 4. DQFormer：有语义与空间来源的 thing/stuff query

正式题名：*DQFormer: Toward Unified LiDAR Panoptic Segmentation With Decoupled Queries for Large-Scale Outdoor Scenes*，IEEE TGRS 63:1–15，2025。2024 预印本使用较短题名。

来源：[作者出版列表](https://yuyang-cloud.github.io/)、[2024 预印本](https://arxiv.org/abs/2408.15813)、[方法原文](https://arxiv.org/html/2408.15813v1)、[作者代码](https://github.com/yuyang-cloud/DQFormer)。重点读 §III-C、III-D；不要将预印本细节冒称为已逐项核对的期刊终版实现。

**论文机制。** 通过 BEV 热图/特征生成有语义的 query：thing 利用预测中心候选，stuff 使用类别固定的可学习 query；再进行 mask 解码与多尺度融合。它在生成 query 时引入语义和空间信息，提供了分类与 mask 学习分工的另一种路线。

**项目证据。** E2-C 已说明单独减弱 NO_OBJECT 抑制不足以获得合格改善。当前后处理让符合条件的 thing/stuff query 共同参与逐点竞争，最终只导出 thing。但没有证据证明这种共同竞争是主要根因，E2 的净收益也不能为完整 DQFormer 架构背书。

**准入与拆分。** 先在固定权重诊断中确认 thing/stuff 候选的空间归属与干扰，再决定是否值得拆分 query。若进入实现，应把 query 分工、BEV 中心生成、多尺度融合分别列为变量，保留同骨干控制；完整换成 DQFormer 只能作为新的系统基线，不能将收益归因于其中一个模块。中心监督的来源、极小实例中心可靠性及额外数据暴露也需写入方案。

当前建议作为中期设计参考，优先级低于完成审查及窄范围 E2-Q。它不是把 NO_OBJECT 改成另一个数值。

## 5. Mask Scoring R-CNN：让分数反映 mask 质量

完整题名：*Mask Scoring R-CNN*，CVPR 2019。

来源：[论文](https://arxiv.org/abs/1903.00241)、[CVF 出版页](https://openaccess.thecvf.com/content_CVPR_2019/html/Huang_Mask_Scoring_R-CNN_CVPR_2019_paper.html)、[作者代码](https://github.com/zjhuang22/maskscoring_rcnn)。重点看 MaskIoU 分支与 mask score 的构造。

**论文机制。** 预测 mask 的 IoU 质量，用其校准分类置信度不足以代表掩码质量的问题。原论文是二维 COCO 实例分割，迁移到稀疏 LiDAR 是新的假设。

**项目证据。** 当前 [extract_instances](D:/Github/mmb4dl/mllm/maskpls_b4dl/model.py:115) 用类别概率作为 score，逐点竞争使用 `mask_probability × class_score`，没有独立 IoU 质量头。C1 的候选更多但 FP 也更多，使“分数是否正确反映质量”值得审查；它不直接证明新评分就会有效。

**先诊断，再训练。** 先固定 F/C0/C1，分析类别分数与正确类别 IoU、覆盖率、纯度的关系。若要精确重放竞争/过滤，需要补采集全部点级概率、query 映射和过滤轨迹；现有 E2 保存的二值 mask 不够。可把 GT IoU 重评分作为诊断上界，但必须标注 oracle，不当作可部署结果。

若存在明确质量排序空间，再设计仅使用训练集监督的小型质量头，与原评分及简单非学习评分对照。Mask3D 的 class confidence 与平均 mask confidence 组合也是可参考的简单方案，但它与学习 MaskIoU 头不是同一种方法。改变分数会改变现有阈值的含义，运行前需明确分数范围、阈值策略和同等预测预算/precision-recall 比较，不能测试后挑阈值。

质量评分不能凭空补出缺失的几何候选，且可能通过删除预测提高 Precision 却损害 Recall。因此它是误检审查后的条件分支，不是当前最大几何瓶颈的完整解决方案。

## 6. 后续方向：先满足对应阶段的证据条件

### SphereFormer：先证明问题在稀疏远距特征

*Spherical Transformer for LiDAR-based 3D Recognition*，CVPR 2023。[论文](https://arxiv.org/abs/2303.12766)、[作者代码](https://github.com/dvlab-research/sphereformer)。径向延伸窗口有助于聚合远距稀疏点与近处上下文。

当前 40m+ 目标最终只有 5/420 命中，但距离、点数、类别会共同变化。先按点数/类别控制分组，检查多尺度特征和插值；如果局部特征干预提供支持，再考虑替换骨干。当前 0.05m 格点纯净既不证明骨干充分，也不构成替换骨干的因果证据。额外预训练数据与初始化收益必须单独报告。

### Mask4D：空间候选稳定后研究跨帧 query

*Mask4D: End-to-End Mask-Based 4D Panoptic Segmentation for LiDAR Sequences*，RA-L 2023，ICRA 2024 展示。[作者代码与论文信息](https://github.com/PRBonn/Mask4D)、[论文 PDF](https://www.ipb.uni-bonn.de/pdfs/marcuzzi2023ral-meem.pdf)。跨帧 query 传播可作为时序关联参考。本轮核验了仓库与出版信息，作者 PDF 链接读取超时，未将其作为本轮新精读全文。

当前要先获得可靠单帧实例。之后独立评测新生、消失、遮挡与身份切换，关联到稳定实例身份；不要把逐帧 query 编号当轨迹，也不要以 GT 身份参与的 teacher forcing 代替自由推理验收。

### Grounded 3D-LLM：回答中的 referent token 绑定到实例

*Grounded 3D-LLM with Referent Tokens*，2024 预印本。[论文](https://arxiv.org/abs/2405.10370)、[项目页](https://groundedscenellm.github.io/grounded_3d-llm.github.io/)、[作者代码](https://github.com/InternRobotics/Grounded_3D-LLM)。借鉴 referent token 与短语—区域对齐接口；此处不将其标为已核验的 ECCV 论文。

本项目先人工确认现有绑定候选，再建立“单帧问题→自由生成回答→唯一实例→原始点掩码”的闭环，分别报告候选召回、候选内选择准确率与端到端命中，并保留无法解析、无对象和歧义样本作为失败分母。不能将官方 QA 的候选引用审计直接写成自由生成回答绑定通过。空间、绑定与语言联合训练目前仍应后置。

## 7. 既有 E1/E2-C 的基础论文及解释边界

- [DETR，ECCV 2020](https://arxiv.org/abs/2005.12872)：集合预测、二分匹配与 no-object 分类权重的机制来源。0.1→0.05 和 3 轮预算是本项目敏感性设计；论文不保证该取值适合当前数据。
- [Mask2Former，CVPR 2022](https://arxiv.org/abs/2112.01527)：masked attention 的机制来源。当前已有相关结构，E1 也未支持首层普遍不可见；论文不能单独证明放开首层就会改善当前小目标。

这些文献说明候选改动“为什么值得检验”，不替代本项目的受控实验。当前唯一完成的分类权重对照是 E2-C，结论是不采纳 0.05；本文其余新方法均尚未在本项目形成可验收收益。

## 8. 下一轮应交付的最小证据

先完成 42 条 FP 与旧标签疑点审查，再根据证据选择一条分支。任何结构改动的方案都需同时包含：

1. 具体假设、对应论文机制，以及本项目已经观察到的触发证据。
2. 唯一变化与同期控制，明确继承/重置参数，保持数据、随机流和训练预算可比较。
3. 固定主要终点，完整的小目标/类别/距离/场景结果，以及 FP、忽略区、自车点变化。
4. checkpoint、代码、manifest 身份和独立匹配审计；失败记录与人工不确定项保留。
5. 通过开发筛选后再进入多种子与真正留出验证，之后才扩大到语言和时序任务。

这轮文献检索的用途是缩小下一步实验范围。优先读 P3Former 理解空间约束，再读 Mask3D 核对 E2-Q 的可辨识对照；DQFormer 与质量评分按人工审查结果决定是否进入实施。
