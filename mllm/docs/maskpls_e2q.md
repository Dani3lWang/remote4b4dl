# E2-Q：query 内容与输入空间位置初始化对照

依据 Mask3D（ICRA 2023）Query Types / Table IV，检验已有低纯度、混合实例候选是否能由初始化改变改善。它是固定 epoch14 父模型下的有限预算适应实验；初始化不是已证实根因，也不是完整 Mask3D 复现。

| 臂 | 初始内容 | 初始位置 | 实际参与训练的 query 表 |
|---|---|---|---|
| Q0 | 新可学习 embedding | 新可学习 embedding | 内容、位置 |
| Q1 | 固定零向量 | 与 Q0 同初值的可学习 embedding | 位置 |
| Q2 | 固定零向量 | ROI 内输入点 FPS 的现有三维编码 | 无；两个旧表仅作固定零占位以保持 state_dict 接口 |

三臂共同移除旧 query 历史，共有网络逐张量继承同一 epoch14；共有网络全部训练。新 query 使用独立 CPU 随机流，Q0/Q1 位置同初值。优化器、调度器统一重置；原 `load_native` 和普通 `load_warm_start` 的精确恢复/损失迁移规则不放宽。模型预测仅消费原始 XYZ/intensity。

FPS 使用米制 ROI 输入坐标、CPU FP64 距离；起点为离传感器原点最远的点。重复坐标保留第一个原始行，距离并列取第一个原始行，不足128个唯一点时循环已完成的 FPS 序列。位置编码沿用 `x/48,y/48,z/4` 的现有 PositionalEncoder，不增加投影层；禁止 GT 中心、类别、答案或相机引导。零内容只指 decoder 的初始内容，后续层正常更新特征。

## 执行顺序

使用独立部署目录及已有 CUDA wqlc 环境，`run_maskpls_e2q.py` 提供：

1. `prepare`：CPU 核对父 checkpoint/源码身份、manifest、原始点/完整GT/panoptic 与划分；固定6轮764帧顺序，预生成4584组匹配/损失采样并存储哈希。三臂共享同一批文件，模型随机数消耗不能改变数据流。输出目录必须全新。
2. `smoke`：三臂真实帧前反向，检查有限损失/梯度、固定表无梯度、共有网络有非零梯度、共享初始化一致。检查128个 FPS 位置对应的原始行。优化器更新0次。另用未重置 query 的 F 完整评估64帧训练探针和96帧开发集，先复现188 TP / 448输出 / 260 FP再训练；全量分桶差异记录，跨硬件不假定浮点逐位一致。
3. `run`：依次 Q0/Q1/Q2，各6轮、1146更新、4584帧呈现，总3438更新、13752帧呈现。FP32、batch1、accumulate4、AdamW lr1e-4、wd0.01、clip1；6轮lr恒定。128 queries、0.05m体素、background忽略区负监督、point_mean BCE、NO_OBJECT=0.1及0.25/0.5/0.8阈值不变。
4. `audit`：从源点云/GT/panoptic独立重算原点轴、ROI、IoU与最大基数匹配，核对所有分桶、采样/帧流、优化器计数、固定表不变、checkpoint与评估状态指纹一致。
5. `finalize`：固定第6轮比较，生成 `comparison.json`、`completion.json` 和中文报告。没有自动采纳新模型，也不启动E3或语言/时序训练。

第0/2/4/6轮各评估64+96帧，三臂共1920次评估；F复现160次、smoke另3次。第6轮为主要终点，不以中途最好结果代替。非有限值、身份/点轴/GT泄漏立即失败；第2/4/6轮连续两次全部TP或小目标几何TP低于F的一半，记提前失败。第0轮不纳入该提前停止规则。

原生标签及人工不确定项均保留。距离按评测有效GT点质心的水平距离分0–10、10–20、20–40、40+米；与点数、类别和全部8场景共同报告。逐GT另记最佳原始query的IoU、覆盖率和纯度；这些GT派生量仅用于离线诊断。独立SciPy最大基数、再最大总IoU匹配，原生Hungarian另确认基数；分桶匹配归属固定。

## 采纳门槛

Q2的最终TP至少高于 `max(F,Q0,Q1)+10`，Precision最多下降2个百分点，1–10点最终TP不退步、小目标几何TP至少增加20；中/大目标Recall相对每个同期控制最多下降2个百分点，负区域/自车和至少5/8场景约束沿用原方案。Q2同时对Q0/Q1接受约束；只优于Q0不足以证明FPS有效。Q1另与F/Q0报告内容初始化筛选，不冒称位置策略收益。

本轮使用已暴露开发集和单个后续训练种子。工程筛选通过仍不等于统计显著、真正留出验证或端到端回答绑定通过。实测训练显存/耗时须取本轮CUDA检查与训练日志，不能用旧无梯度诊断估算。
