# E2-P：保留成熟 query 的显式位置 mask 残差对照

E2-Q 已完成，FPS 未通过门槛，继续保留原 epoch14 F。本实验检验小目标原始候选过宽、纯度低是否能由显式位置分支改善。现有 decoder **已有位置编码**，不能将该现象描述成缺少位置输入。

参考 [P3Former §3.2–3.4](https://arxiv.org/html/2303.13509v1) 的位置/特征 mask 分离思路；这里是自定义残差消融，**不是 PA-Seg、MPE、MFA 或完整 P3Former 复现**。第一轮只增加一个 mask 分支，不改变坐标编码、骨干或 query 初始化。

## 方法与控制

令 `h=decoder_norm(query)`、`f=mask_feat_proj(point_feature)`、`p=现有PE(原始XYZ)`，保留原来的 `L=mask_embed(h)·(f+p)`。

| 臂 | mask logit | 新增参数 | 目的 |
|---|---|---:|---|
| P0 | L | 0 | 原 F 继续训练，同期预算控制 |
| P1 | L + residual_mlp(h)·f | 197,376 | 相同容量特征分支控制 |
| P2 | L + residual_mlp(h)·p | 197,376 | 显式位置 mask 分支 |

残差 MLP 为三层 `256→256→256→256`，前两层 ReLU；P1/P2 使用同一独立 CPU 随机流配对初始化，最后一层权重和偏置均为零。没有零标量门，首步末层有梯度，后续隐藏层可学习。三个臂逐张量继承同一 F 的所有共有权重，**包含成熟内容及位置 query，不重置旧 query**。全网参与训练，优化器/调度器重新初始化。

分支用于初始预测及全部9层预测，参与同一辅助损失和后续 attention mask。主分支及分类头保持原结构。P2 的残差点基仅由原始 XYZ 的既有 `x/48,y/48,z/4` 编码产生；query 特征仍来自网络。预测不消费 GT、目标中心、相机、类别或答案。GT 只用于损失、共享采样与离线评估。

## 固定执行顺序

独立部署目录，使用既有 CUDA wqlc；入口 `mllm/scripts/run_maskpls_e2p.py`：

1. `prepare`：检查父checkpoint哈希/源码身份及完整nuScenes元数据；从已完成且独立审计的E2-Q复制6轮帧流和4584组监督采样，逐文件验hash，并重新读取764训练帧、96开发帧的源点/GT/panoptic。拒绝已有输出目录。
2. `smoke`：三臂真实帧；在同一份缓存骨干特征上，所有10层mask/类别及最终query初始化输出必须逐值严格相同。CUDA稀疏骨干重复前向存在微小浮点差异，因此不把跨次重算骨干的浮点哈希当作插入分支的等价标准；严格等价与完整F复现均保留。检查有限损失/梯度和新增末层非零梯度。每臂执行2个一次性更新，验证严格checkpoint恢复与Adam下一步更新一致，全部丢弃，不计入正式训练。重新完整评估F的64训练探针+96开发帧，复现188 TP/260 FP等离散总数后才能训练。
3. `run`：依次P0/P1/P2，各6轮、1146更新、4584帧呈现，总3438更新。每轮764帧，FP32、batch1、累积4、AdamW lr1e-4/wd0.01、clip1、恒定lr。128 queries、0.05m、background、point_mean BCE、NO_OBJECT=0.1、0.25/0.5/0.8阈值不变。保存每轮checkpoint。
4. `audit`：独立CPU从原始点/GT/panoptic重算ROI、有效点轴、IoU、一对一匹配及全部分桶；检查全部26评估范围2080帧、实际采样/帧流/更新计数、Adam状态、每份checkpoint与评估指纹。原生未使用level_embed保留并单独记录。
5. `finalize`：固定第6轮为主终点，不挑中途最好权重。保留全部失败/提前停止，不自动替换F或启动E3。

第0/2/4/6轮各评估64+96帧；F复现160帧。额外smoke为3次完整模型前反向、1次缓存骨干前向、4次同特征decoder前向、6次一次性更新。非有限值、身份、点轴或输入泄漏立即失败；第2/4/6轮连续两次总TP或小目标几何TP低于F一半，标记提前失败。失败后保留现场，在新目录修正并重新准备，禁止直接覆盖失败证据重跑。

首部署CUDA短测（正式训练0更新）查出：原F重复前向mask最大差约9.2e-5、骨干特征约3.8e-6，诊断帧全部mask阈值/类别argmax一致。共享同一骨干特征后，P0重复及P1/P2全部10层decoder输出严格等价（最大差0）。据此改为同特征严格检查，未改模型、损失、采纳门槛；失败目录保留。

## 预先固定筛选门槛

P2 必须同时对 F、同期 P0 和 P1 满足：总最终TP ≥ 控制最大值+10；Precision下降≤2个百分点；1–10点最终TP ≥ 控制最大值+10；小目标几何TP ≥ 控制最大值+20；小目标最佳候选纯度中位数 ≥ 控制最大值+0.01；覆盖率中位数下降≤0.05；最佳IoU中位数不退步。分母固定为全部1938个小目标，包含未命中目标。

中/大目标Recall相对每个同期控制最多下降2个百分点；8场景中至少5个相对每个同期控制Recall不退步。ignored比例最多增加0.01，ego点数不超过控制最大值×1.1+100。逐目标记录和点数、类别、距离、场景分桶均保留；GT辅助最佳query仅用于描述性诊断，query ID不作为跨帧或跨臂对象身份。

该实验是已暴露开发集上的单种子机制筛选。通过后仍需人工检查、多种子和真正留出评估；不等于空间性能、语言绑定或跨帧跟踪已验收。
