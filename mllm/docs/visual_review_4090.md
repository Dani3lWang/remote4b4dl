# Visual 分支审查与 RTX 4090 改进

审查基点：`Visual` 分支 `82f5062`，2026-10-02。范围包含 Gradio 查看入口、
评测结果关联、论文案例导出、模型加载和多模态生成，以及 B3 单 GPU 入口。

## 发现与修复

| 优先级 | 原问题与影响 | 改进 |
|---|---|---|
| P1 | `python -m vtimellm.demo_gradio` 先执行包初始化，纯查看也导入模型依赖 | 模型导出改为延迟导入；独立 CPU 查看依赖 |
| P1 | 相同问题和 GT 在多个场景重复时，旧预测按顺序配对；跳过失败样本后可能关联错场景 | 只接受唯一场景及输入帧身份；歧义样本保持未关联 |
| P1 | 未关联评测样本的案例图自动保留默认场景，可能导出与答案无关的图片 | 清空场景和帧号，要求手动选择；同时检查 scene_id / scene_token 一致性 |
| P1 | LiDAR 特征展开后 `cache_position` 仍以文本长度计算；eager 路径可直接维度报错 | prefill 与 decode 均根据真实 KV cache 长度计算位置 |
| P1 | B3 门槛固定为 28000 MiB，4090 无法满足并等待最多 72 小时 | 总显存不足时立即报错；提供 4090 配置及所选 GPU 检查 |
| P2 | 查看依赖继承训练全栈，NumPy 2 与 nuScenes 旧 matplotlib 不兼容，且强制安装 flash-attn | 查看清单使用 NumPy 1.x；在线问答清单使用与项目说明一致的模型版本及原生 SDPA |
| P2 | 对话无限增长，未计算 LiDAR 展开长度；失败时会改写原对话 | 预算包含完整特征与输出 tokens，裁剪完整旧轮次，并在成功后提交新会话 |
| P2 | 查看与推理共享可变 LRU，播放就可能把特征搬到 GPU | 缓存加锁，特征留在 CPU，单并发 GPU 推理 |
| P2 | 未显式显示 oracle 输入选择和 METEOR 后端 | 看板提示 answer_frames 与指标口径，论文图标注仅供参考 |
| P2 | 深色界面背景规则与标题颜色导致对比度不足 | 分开设置背景色和渐变，显式设置标题前景色 |

增加 `--trainer_state` 显示 loss、eval_loss 和 learning rate，按优化器更新步数
绘制；不读取模型权重，不启动训练。详细参数和命令见
[Demo 使用说明](lidar_gradio_demo.md)。

## 4090 配置

- 在线场景问答默认 `dtype=auto`（支持时 BF16）和 `attn_implementation=sdpa`。
- 输入完整场景特征；默认最大上下文 4096、输出 512，实际服从模型上限。
- `B4DL_TRAIN_PROFILE=rtx4090`：micro-batch 1、累积 128、现有 ZeRO-3 CPU
  offload、20000 MiB 空闲门槛，有效 batch 128。
- checkpoint、日志、评测目录带 `-rtx4090` 后缀；不从原 8×16 目录自动恢复。
- 训练退出码向调用方传播，避免训练失败被最后一条日志命令隐藏。

## 验证与边界

在独立 `wqlc` Python 3.10 环境安装查看清单成功；可选推理清单以 PyTorch
2.8 CPU wheel 验证，`pip check` 通过。CPU 回归覆盖 CLI 不加载模型、场景
关联、几何、训练日志、上下文裁剪、案例图导出及 4090 显存门槛。

小型随机 Llama 模型从磁盘通过正式 loader 加载，在 FP16/eager 和
BF16/SDPA 下分别验证 4-token 多模态生成；相同输入的缓存与无缓存输出一致。
这验证加载参数和 KV 位置，不代表 7B 真实权重的语义质量或吞吐。

Gradio 6.0.1 浏览器验证使用合成场景和评测数据：训练曲线可见，未关联样本
不选择默认场景，关联样本可载入同步帧并生成可下载的 PNG / PDF，无浏览器
错误。真实 nuScenes 相机标定和模型 QA 仍需在用户数据上验收。

当前执行环境没有 CUDA、真实模型权重和 nuScenes 数据。没有执行完整训练、
六任务真实评测或 4090 显存/速度测量，也没有据此声称模型分数提高。CPU
offload 的速度与主机内存需求需要实测；有效 batch 相同也不保证训练轨迹完全
相同。训练原依赖清单与 `CLAUDE.md` 中记录的实测栈仍有差异，训练应使用
已通过 preflight 的环境；本次新增清单用于独立查看及在线问答。

## 实机验收建议

1. 用 `v1.0-mini` 检查点云、六路相机、框和轨迹在同一帧对齐。
2. 用真实 B3 adapter、projector 与同代场景特征运行在线问答，检查长对话和
   过长问题反馈；记录峰值显存及 tokens/s。
3. 在训练环境运行 preflight 后用 4090 配置进行短训练，记录显存、吞吐和
   CPU 内存，再决定是否执行完整 2 epochs。
4. 以同一测试集、特征与输入选择重新生成评测结果，将新曲线和结果导入
   看板；分别声明精度、METEOR 后端及 oracle 输入选择。
