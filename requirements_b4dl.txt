#         pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu124
#         pip install -r requirements_b4dl.txt
#
# ⚠️ 版本冲突说明:
#   项目根 / mllm/ 两套 requirements 在以下包有版本分歧:
#
#   | 包            | mllm/requirements.txt | 根 requirements.txt | 本文件采用        |
#   |---------------|----------------------|---------------------|-------------------|
#   | transformers  | 4.31.0               | 4.37.2              | 4.31.0 (mllm 侧) |
#   | peft          | 0.4.0                | 0.18.0              | 0.4.0  (mllm 侧) |
#   | deepspeed     | 0.16.4               | 0.18.2              | 0.16.4 (mllm 侧) |
#   | flash_attn    | 2.7.0.post2          | 2.8.3               | 2.7.0  (mllm 侧) |
#   | clip          | 0.2.0                | 1.0                 | 1.0    (根侧)     |
#
#   原因: mllm/vtimellm/train/llama_flash_attn_monkey_patch.py 对
#   transformers==4.31.0 的 LlamaAttention.forward 做了 monkey-patch;
#   mllm/vtimellm/model/builder.py 的 LoRA 加载/合并依赖 peft==0.4.0
#   的旧式 API (peft >=0.5.0 变更了 get_peft_model / PeftModel 接口).
#   这两个无法安全升级, 因此整个环境以 mllm 的低版本为准.
#
#   如果你想尝试用根目录的新版 (4.37.2 / 0.18.0), 需自行修改 builder.py
#   适配新版 peft API, 并验证 flash_attn monkey-patch 是否兼容.
# =============================================================================
